# Contributing

Use Swift 6 and macOS 13-compatible APIs. Keep the scanner read-only and cleanup isolated behind TrashOperations. Do not add networking, analytics, paid restrictions or dependencies without a clear product justification. Keep unknown files unknown. Never broaden eligibility to make a test pass.

Run the fixture tests and localization check, build Debug and Release, and include relevant evidence with each change. Tests must use explicit test mode and fixture-only Trash; never run destructive tests in real user folders. No automatic protected-path bypass exists in production.

The Xcode project is generated by scripts/generate_project.py. Run it after adding or removing Swift sources. Localization source dictionaries are in scripts/localizations.py and scripts/translation_supplements.py; regenerate the string catalog after edits. Have fluent speakers review technical translations before a public release.

Use the release-gate checklist in docs/architecture.md. Performance, VoiceOver, RTL, permissions, interrupted journaling and recovery on supported macOS versions need manual acceptance coverage in addition to CI.
